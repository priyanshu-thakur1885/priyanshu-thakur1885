A full-stack expense management application designed to help users track and manage their finances efficiently.

**Tech Stack:**

`React.js` `Node.js` `Express.js` `MongoDB` `Tailwind CSS` `Socket.io` `Auth0`

**Features:**

* 🔐 Secure user authentication with Auth0
* 💸 Add, edit and delete expenses
* 📊 Track and manage financial data
* ⚡ Real-time functionality using Socket.io
* 📱 Responsive user interface
* 🗄️ MongoDB-based data persistence
